To complete SEO setup, you need to create an og-image.png file.

Recommended specifications:
- Size: 1200x630 pixels
- Format: PNG or JPG
- File name: og-image.png
- Location: /public/og-image.png

This image will be used as the preview thumbnail when your site is shared on:
- WhatsApp
- Telegram
- Facebook
- Twitter
- LinkedIn
- And other social media platforms

Design tips:
1. Include the TikFlow logo
2. Add text like "Download TikTok Videos Without Watermark"
3. Use your brand colors (#195FD7 blue)
4. Make sure text is readable at small sizes
5. Keep important content in the center (some platforms crop edges)

Tools to create OG images:
- Canva (canva.com)
- Figma (figma.com)
- Adobe Express
- Or any graphic design tool

Once created, place it in the /public folder as "og-image.png"
